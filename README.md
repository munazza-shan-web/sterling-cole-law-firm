# Sterling & Cole LLP — Law Firm Website

A polished, responsive, multi-page fictional law-firm website created as a web-development portfolio project.

## Pages
- Home
- About
- Attorneys
- Practice Areas
- Corporate Law (individual service page)
- Case Results
- Insights / Blog
- Contact / Consultation

## Features
- Premium dark navy, gold, and ivory visual system
- Responsive desktop/tablet/mobile layout
- Sticky navigation with mobile menu
- Consultation intake form with front-end confirmation
- Attorney cards
- Practice-area cards
- Representative case results
- Blog/insights grid
- Strong CTA sections
- SEO-friendly page titles and descriptions
- No frameworks or paid dependencies

## Tech
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` directly or use VS Code Live Server.

## GitHub Pages
Upload all files and folders to the repository root, then enable GitHub Pages from the `main` branch and `/root`.

> Disclaimer: Sterling & Cole LLP is a fictional brand created solely for portfolio demonstration. The attorneys, case results, address, and contact details are fictional.
