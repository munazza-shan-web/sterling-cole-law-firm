# ⚖️ Sterling & Cole LLP — Law Firm Website

A modern, professional, and fully responsive multi-page website designed for a fictional law firm, **Sterling & Cole LLP**.

This project demonstrates my ability to build polished business websites for **law firms, attorneys, legal consultants, and other professional-service businesses**.

## 🌐 Live Demo

**Live Website:**
https://munazza-shan-web.github.io/sterling-cole-law-firm/

## ✨ Features

* Professional dark navy, gold, and white design
* Fully responsive layout
* Mobile-friendly navigation
* 8 complete website pages
* Attorney profile section
* Multiple legal practice areas
* Individual Corporate Law service page
* Case results section
* Legal blog / insights section
* Consultation request form
* Strong calls-to-action
* SEO-friendly page structure
* Clean and reusable code
* No paid frameworks or dependencies

## 📄 Pages

1. **Home** — Professional introduction, services, results, and calls-to-action
2. **About** — Firm background, approach, and values
3. **Attorneys** — Attorney profiles and specialties
4. **Practice Areas** — Overview of legal services
5. **Corporate Law** — Detailed individual practice-area page
6. **Case Results** — Representative case and transaction outcomes
7. **Insights / Blog** — Legal articles and resources
8. **Contact** — Consultation request and contact information
